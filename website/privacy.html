Privacy Policy

Last updated: 2026-04-20

This website and project are operated by ByteBard (CVR 38774468), a company registered in Denmark.

Simple License Server is a self-hosted product. In typical deployments, license and activation data are stored only in infrastructure controlled by the operator.

Data controller context

For this public website, ByteBard acts as data controller. For self-hosted product deployments, the operator of the deployment is normally the data controller for license and activation metadata processed by their instance.

What data may be processed

Depending on your integration, metadata can include items such as customer email, order id, machine fingerprint, and timestamps related to license events.

How data is used

Data is used strictly for license lifecycle operations, including generation, activation, validation, revocation, and audit history.

Website analytics

We use self-hosted Umami analytics on the public website to understand page traffic and improve site content. This tracking applies to the website only and does not apply to the Simple License Server software or self-hosted instances run by operators.

GDPR rights (EU/EEA)

If GDPR applies to your data, you may have rights to access, rectification, erasure, restriction, objection, and data portability. Requests should be directed to the controller responsible for the relevant data processing context.
