API Example
POST /activate 
curl -X POST http://localhost:8080/v1/activate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <your_api_key>" \
  -d '{
    "license_key": "ABCD-1234-EFGH-5678",
    "fingerprint": "machine-uuid-9876",
    "metadata": {
      "os": "linux",
      "version": "1.0"
    }
  }'

Simple to Deploy

Packaged as a single Docker container. Zero complex dependencies, external databases, or heavy configurations required.

Universal API

Integrate with any language or framework using standard REST endpoints and JSON payloads.

Built for Performance

Written in Go. Validates thousands of licenses per second with minimal memory footprint and sub-millisecond latency.

Self-hosted software licensing, without the bloat

Simple License Server is a self-hosted license server for SaaS and desktop developers who need a reliable license key API. Run it in Docker, store data in Postgres, and integrate generation, activation, validation, revocation, and deactivation into your product with predictable JSON endpoints.

Made for API workflows

Use it behind payment webhooks, admin tools, or internal backends. The API stays small and consistent so your integration remains easy to maintain.

Production-friendly defaults

Built in Go with explicit timeout and rate-limiting controls. Deploy as one container and keep operational overhead low.

Built for self-hosting

Your keys and license data stay in your infrastructure. No third-party lock-in and no mandatory vendor dashboard.

Frequently asked questions

Can I run this with Docker Compose?

Yes. The project includes a Docker Compose setup for the API and Postgres so you can run a local or server deployment quickly.

Does it support custom activation flows?

Yes. Activate and validate endpoints are fingerprint-aware, making it straightforward to implement your own seat and device policies.

Is this a hosted licensing service?

No. This project is self-hosted first. You operate it in your own environment and keep full control over availability and data handling.

Where can I find API docs?

Start with the repository README and API design documents on GitHub for endpoint behavior and integration examples.
